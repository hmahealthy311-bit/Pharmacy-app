# نرس لينك (Nurseline) 🩺

نموذج أولي تفاعلي (Prototype) لمنصة **تمريض منزلي** مبنية بالكامل على «نرس لينك – وثيقة المفهوم»:
العميل يمسح كود QR في مكان محدد، يفتح الموقع باسم المنصة، ويختار الخدمة والمدة وطريقة الدفع — والممرض يوصله لحد بيتك.

## المزايا المنفذة

- 🧭 **رحلة المريض (٩ خطوات)**: سكان الكود → اختيار الخدمة → التفاصيل → المدة والإضافات → العنوان والموعد → المراجعة → الدفع → التتبع → التقييم.
- 🩹 **الخدمات الخمس**: إعطاء حقنة، تغيير على جرح، تركيب كانيولا، إعطاء محلول، رعاية مريض — بأيقونات وأسعار تجريبية.
- 💉 **قواعد السلامة والحقن**: قائمة الحقن المسموحة ظاهرة دايمًا، ومنع المضادات الحيوية برسالة حمراء فورية «خدمة دي غير متاحة حالياً»، ومراجعة الإدارة لأي حقنة بره القائمة، وإرفاق روشتة.
- ⏱ **المدة والأسعار الإضافية**: كل ٣٠ دقيقة (+ساعة للرعاية) بسعر ثابت، والسعر النهائي يظهر فورًا في المراجعة قبل الدفع.
- 💳 **طرق الدفع الثلاثة**: كاش / انستا باي (مع إثبات التحويل) / دفع أونلاين من الموقع (محاكاة).
- 🛵 **التتبع**: تم القبول → في الطريق → وصل → خلصت الزيارة (محاكاة تلقائية + زر تسريع يدوي).
- ⭐ **تقييم الممرض**: نجوم ١–٥ وتعليق اختياري، بيغذي متوسط تقييم الممرض في تطبيقه ولوحة الإدارة.
- 🎁 **خصم الولاء للمريض الدايم**: ٠٪ → ١٪ → ٢٪ → ٣٪ → ٥٪ على ٥ زيارات ثم تصفير الدورة — بيحتسب أوتوماتيك في شاشة المراجعة.
- 🧑‍⚕️ **تطبيق الممرض**: دخول بحساب مربوط بمنطقة، طلبات المنطقة الجديدة، قبول، تحديث الحالة (في الطريق / وصل / خلصت)، وسجل الزيارات والتقييمات.
- 🗂 **لوحة الإدارة**: إحصائيات، كل الطلبات مع السند اليدوي للممرض، إدارة الممرضين والمناطق، تعديل الأسعار، إدارة الحقن المسموحة، وتقارير حسب المنطقة.

## التشغيل

1. افتح `index.html` في المتصفح مباشرة، أو
2. فعّل **GitHub Pages**: Settings → Pages → Source: `main` / root — وهيتفتح الموقع من رابط المستودع.

> البيانات محفوظة في متصفحك (localStorage). زر «إعادة ضبط البيانات التجريبية» في لوحة الإدارة يرجع كل حاجة للوضع الافتراضي.

## بنية الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الهيكل والصفحات: الرئيسية / حجز خدمة / تطبيق الممرض / لوحة الإدارة |
| `style.css` | الهوية البصرية: أزرق طبي، أبيض، أخضر مفتوح للتأكيدات، أحمر هادي للتنبيهات، خط Cairo، أزرار كبيرة |
| `app.js` | منطق المحاكاة بالكامل: الحالة، الأسعار، الخصم، الطلبات، الممرض، الإدارة |

⚠️ أرقام الأسعار تجريبية وقابلة للتعديل من لوحة الإدارة، والنموذج تعليمي وليس تطبيقًا طبيًا فعليًا.
