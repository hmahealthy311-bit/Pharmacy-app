# نرس لينك (Nurseline) 🩺

نموذج أولي تفاعلي (Prototype) لمنصة **تمريض منزلي** مبنية على «نرس لينك – وثيقة المفهوم»:
العميل يمسح كود QR، **يسجل دخول بالوجه**، يختار الخدمة والأدوية، يأكد عنوانه والملحوظة، يدفع — **والطلب يروح للإدارة** اللي بتوزعه على ممرض في الشيفت حسب الموقع.

## المزايا المنفذة

### رحلة العميل (١٠ خطوات)
- 📷 سكان كود QR (محاكاة) → ترحيب وتحديد الموقع.
- 🙂 **تسجيل الدخول بالوجه** (محاكاة) — بيفتح ملف عميل باسمه وموبايله وعناوينه المحفوظة، وبيتعرف على العميل الراجع.
- 🩹 اختيار الخدمة: حقنة / جرح / كانيولا / محلول / رعاية.
- 💉 الأدوية والتفاصيل: قائمة الحقن المسموحة، منع المضادات الحيوية برسالة «خدمة دي غير متاحة حالياً»، روشتة، «الممرض يجيب معاه الدواء».
- ⏱ المدة والإضافات (كل ٣٠ دقيقة +١٠٠ج — تجريبي).
- 📍 **تأكيد العنوان أو اختيار عنوان تاني** من العناوين المحفوظة + **ملحوظة للممرض** + الموعد.
- 🧾 المراجعة بالسعر النهائي وخصم الولاء.
- 💳 الدفع: كاش / انستا باي (إثبات تحويل) / أونلاين.
- 🛡️ **الطلب يروح للإدارة** ثم تتبع كامل حتى التقييم بالنجوم.

### بوابة الإدارة والتمريض (منقسمة)
- 🔑 **شقين للاختيار: مدير أو تمريض** — لكل حساب **يوزر نيم وباسورد خاص**.
- 🛡️ **أمان**: كلمات المرور مش متخزنة نص صريح (hash + salt)، قفل الدخول ٦٠ ثانية بعد ٥ محاولات خاطئة، الجلسة بتقفل تلقائي بعد ٥ دقايق خمول، إخفاء/إظهار كلمة المرور، مؤشر قوة كلمة المرور.

### شق المدير 🛡️
- 📊 **داشبورد**: طلبات في انتظار التوزيع، قيد التنفيذ، زيارات معمولة، إيراد، متوسط تقييم، ممرضين في الشيفت.
- 🕐 **الشيفت**: مين موجود في الشيفت دلوقتي، تشغيل/إخراج ممرضين، والتوزيع بيتم **حسب الموقع** (الأولوية لنفس منطقة العميل).
- 🩺 **الزيارات**: كل الطلبات وحالتها + **الزيارات المعمولة** بالتقييمات + آخر التقييمات.
- ⚙️ **الإعدادات**: المدير يضيف ممرضين جدد (يوزر/باسورد/منطقة)، يعدّل الاسم واليوزر والباسورد، يحذف، يغير كلمة مرور المدير نفسه، يعدل الأسعار، يدير الحقن المسموحة، وتقارير حسب المنطقة.

### شق التمريض 🧑‍⚕️
- طلبات مُسندة للممرض في انتظار القبول، وتحديث الحالة (في الطريق → وصل → خلصت).
- سجل الزيارات والتقييمات.
- **الممرض يقدر يغير اسمه وكلمة مروره** من إعداداته.

## بيانات الدخول التجريبية

| الحساب | اليوزر | الباسورد |
|---|---|---|
| المدير | `admin` | `Admin@123` |
| ممرضة ١ (سارة — مدينة نصر) | `sara` | `Sara@123` |
| ممرضة ٢ (منى — المعادي) | `mona` | `Mona@123` |

> المدير يقدر يضيف ممرضين جدد ويغير البيانات من: بوابة الإدارة → الإعدادات.

## التشغيل

1. افتح `index.html` في المتصفح مباشرة، أو
2. فعّل **GitHub Pages**: Settings → Pages → Source: `main` / root.

> البيانات في متصفحك (localStorage). «إعادة ضبط البيانات التجريبية» من إعدادات المدير بترجع كل حاجة.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الهيكل: الرئيسية / حجز خدمة / بوابة الإدارة والتمريض |
| `style.css` | الهوية البصرية: أزرق طبي، أبيض، أخضر للتأكيدات، أحمر هادي للتنبيهات |
| `app.js` | منطق المحاكاة: الرحلة، الدخول بالوجه، الحسابات المحمية، الشيفت والتوزيع |

⚠️ أرقام الأسعار تجريبية، والمسح بالوجه محاكاة (في التطبيق الحقيقي بيشتغل بكاميرا + خادم تحقق)، والنموذج تعليمي وليس تطبيقًا طبيًا فعليًا.
